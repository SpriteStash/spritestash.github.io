Demon Warlord — Dark Fantasy Bestiary / Pack 03

Sprite Stash. ID9, warrior boss. Includes Demon Warlord only.

Included

2491 production animation PNG files across 39 component manifests and 174 original spritesheet pages. Evaluated layers, Composed frames, reusable local effects and body keys are alternative representations; they are not this many unique poses. Spritesheets arrange the same frames. Original pixels, manual edits and soft RGBA alpha are preserved. The engine integration contains 8 presentation states, an Attack1 gameplay alternative and a separate contact effect, stored in 24 lossless 2048x2048 atlas pages.

Compatibility and scope

Unity 6000.0.47f1 / Built-in and Unreal Engine 5.8.3 / Paper 2D, tested in Windows editors. Other versions, URP/HDRP, UEFN and packaged platforms are not validated. Unreal uses native Blueprint assets with no authored C++ or runtime Python dependency. Includes exact animation playback, configurable Rage state/modifier data and a caller-triggered contact effect. Enemy AI, movement controller, damage application, gameplay collision, audio and a complete combat system are not included.

Open the demo

Unity: import the .unitypackage into a Built-in project. Open Assets/SpriteStash/DemonWarlord/Scenes/SC_DemonWarlordDemo.unity and press Play. The buttons select states; All states plays the approved showcase.

Unreal: extract the complete project, open DemonWarlordDarkFantasyBestiaryPack03.uproject in Unreal 5.8.3 and enable Paper 2D. Open Maps/L_DemonWarlordOverview and press Play. Keys 1-8 select Idle, Walk, Rage activation, Rage Idle, Attack1, Attack2, Hurt and Death. The automatic overview plays each state once and repeats only the full sequence.

Unreal documentation is a usable native level at Documentation/L_DemonWarlordGuide. Maps/L_DemonWarlordSourceAssets displays the native animation banks and atlas views. README.txt and PLAYBACK.json are beside the native guide on disk.

Exact state timing

Idle 1600 ms and Walk 1800 ms loop. Rage activation (Furia) is 2200 ms once, then Rage Idle (IdleFuria) loops every 1600 ms. Attack1 1080 ms, Attack2 2960 ms, Hurt 320 ms and Death 2800 ms play once. Death ends fully absent. The complete showcase is 14360 ms: Idle / Walk / Rage / Rage Idle / Attack1 / Attack2 / Hurt / Death. It is a presentation sequence, not a required gameplay transition graph. Review-only 600 ms holds are excluded.

Rage/Tracks shares 190 evaluated 20 ms samples: activation uses 1-110 and Rage Idle uses 111-190. Never use the full 3800 ms as the activation duration. The approved version is v6, without rejected v7 crossfades.

Registration, size and alpha

Keep 256 pixels per Unity unit / 2.56 pixels per Unreal centimeter and physical scale 1. Each action retains its approved art registration from the original (128,215) source point. Native storage trims transparent margins only, with a recorded crop and anchor; it does not recenter the monster. Never scale down the body to fit the sword. The source frames are already smoothed and manually corrected. Do not smooth, recolor, rotate, stretch or rebuild them.

Use evaluated components OR Composed, never both. Native reference playback uses Composed; all aura, fades, movement and layer opacity are baked. Render at white tint and alpha gain 1. Preserve RGBA alpha; GIF dither or its dark viewer matte must not be imported. The base red outline remains on every pose, including the manually corrected Walk arm opening.

Attack1 and actual contact

The approved example uses a large slash fixed near the sword at source (510,334), active 500-820 ms. It does not chase the weapon tip. The example contact impact is at (830,770), active 580-800 ms, and is already in the reference Composed frames.

For a real game hit, use PlayAttack1Gameplay rather than the reference attack. It selects the approved evaluated layers without the example contact. Call SpawnContactImpact once with the actual hit world point from your collision system. It plays the exact 220 ms evaluated impact, registered to that point. It does not force a hit time or invisible example target, and never duplicates the reference impact. Unity takes Vector2 XY; Unreal takes Vector XYZ in the X/Z sprite plane. A new contact replaces the single existing contact slot; spawn separate instances in your own system for multiple simultaneous hits.

Attack2

The horizontal cyclone lasts 2960 ms with seven physical turns. Growth is 80-240 ms; the maximum is held 240-2760 ms; decay is 2760-2920 ms, followed by 40 ms of Idle. During the maximum only keys 5-8 repeat at 40 ms each. No repeated growth/decay or extra Idle is inserted. Rear85% and front48% alpha are already baked.

Rage gameplay and attributes

Unity: call DemonWarlordPlayer.ActivateRage(). Unreal: call BP_DemonWarlordController.ActivateRage. After 2200 ms, RageActive becomes true and Rage Idle starts. rageDurationSeconds / RageDurationSeconds begins counting AFTER activation; zero means active until ClearRage is called. A positive value expires the buff at that duration, carrying any remaining time into ordinary Idle. Attack/Hurt recovery returns to Rage Idle while Rage remains active. Death clears Rage and stays absent.

Damage and movement multipliers default to1 (neutral). Configure rageDamageMultiplier/rageMovementMultiplier in Unity or RageDamageMultiplier/RageMovementMultiplier in Unreal. Read DamageMultiplier/MovementMultiplier in Unity or EffectiveDamageMultiplier/EffectiveMovementMultiplier in Unreal from your game code/Blueprint. They are exposed data; this pack does not apply damage or move the monster. These values never change approved animation playback speed. No buff-specific Walk/attack/Hurt/Death artwork is invented; those actions keep their approved art.

The five visual roar pulses start at180/500/820/1140/1460 ms. The final pulse ends1760 ms. Aura and waves use identical rear100% and front22% copies already baked in the approved evaluated art. Do not multiply that opacity again. The persistent Rage Idle has aura only, no new roar waves. No audio or extra sword-fire sequence is included.

Death

The approved natural v4 falls for1200 ms, then body AND sword disintegrate into fine ash for1600 ms. Ash is carried left with slight upward wind; aura disappears with the body. All effects are already present. Never add a second dissolve, round masks or head/feet cut planes. Final frame is transparent and gameplay Death never returns to Idle.

Add and migrate

Unity: drag Prefabs/PF_DemonWarlord into a scene. Use DemonWarlordPlayer.Play with exact names Idle, Walk, Furia, IdleFuria, Attack1, Attack2, Hurt, Death. externalClock=false uses Update; externalClock=true lets the caller supply Advance(milliseconds). Evaluate(milliseconds) is for sampling/inspection, without advancing buff or contact clocks. autoReturnToIdle controls ordinary one-shot recovery. The reusable prefab does not include the automatic showcase controller.

Unreal: drag Blueprints/BP_DemonWarlordController into a level. PlayState indices0-7 follow the showcase order above. Named Play functions are available. AutoPreview and DemoControls default off; AutoReturnToIdle defaults on. Use ActivateRage for gameplay activation. Asset Actions > Migrate on the Blueprint includes native dependencies. Migrate the source-gallery level too if its optional source views are desired. Preserve the product folder and all dependencies.

The raw-art download contains original component frames, sheets, local Shared keys, Contracts, Runtimes, placement/playback data and English documentation. Provenance, historical/rejected versions and review-only previews are omitted. Local keys are reusable alternatives, never extra layers over evaluated effects. Original art metadata engine_tested=false records the art handoff; integration tests are recorded separately for this release.
