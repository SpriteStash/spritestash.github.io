SPRITE STASH - GOBLIN RAIDER ISOMETRIC

Unity integration guide

SETUP

Import the unitypackage. Open Scenes/SC_GoblinRaiderIsometricOverview and enter Play Mode. Select one of eight directions and one of five animation states. All movements runs the approved 5650 ms promotional sequence; its extra 1500 ms corpse hold is presentation only.

USE IN YOUR PROJECT

Drag Prefabs/PF_GoblinRaiderIsometric into a scene. GoblinRaiderIsoPlayer.Play(state, direction) starts a state: Idle=0, Walk=1, Attack=2, Hurt=3, Death=4. Direction order: N, NE, E, SE, S, SW, W, NW. SetDirection preserves the current clock. Advance takes milliseconds. SampleAt samples a pose without progressing time. returnToIdle controls Attack/Hurt recovery; Death always stays on the last corpse frame.

PRODUCTION TIMING

Idle 1190 ms loop; Walk 1100 ms loop; Attack 560 ms; Hurt 400 ms; Death 900 ms once. Variable per-frame times are in the bank and ENGINE-PLAYBACK.json. Cut trail plays from 290 to 410 ms of Attack, peak 310 ms. The player uses back and front effect layers only; the full effect bank is an alternative, not an extra overlay.

REGISTRATION

PNGs retain original canvases and pixels. 128 pixels per Unity unit, image-center registration, transform scale 1. Body 256/320 and effects 640 use compensated image centers. These are image-registration origins, not universal anatomical foot pivots. Match a gameplay collider separately. No per-pose alpha trimming, mirroring of the monster, rescaling or recoloring is applied. South FX remains entirely in front.

MODIFICATION

The bank stores 40 body sequences and three alternative FX banks. Change direction and state via the player API. Do not replace variable frame durations with uniform FPS. Demo logic is separate from the reusable player. These assets do not implement enemy AI, navigation, collisions or damage. No audio.

CONTENT NOTES

NE/SW Death blade tips retain the approved source truncation. Attack recovery reuses the starting pose. Source-generation and private handoff files are not included. Original spritesheets are included in Textures/Spritesheets as source layouts; production playback uses individual frames. The separate art download contains the same approved original frames and sheets.

LICENSE

Terms depend on the store of purchase; see LICENSE.txt. AI-assisted production is described in AI-Disclosure.md.

NATIVE UNITY CLIPS

Animations contains 40 named AnimationClips with the exact variable body and split-effect timing. PF_GoblinRaiderIsometricAnimator is an optional Animator prefab: call Animator.Play("Attack_SE") etc. Its controller has no gameplay transitions; Death holds the corpse. Use this alternative OR the script-driven player, never both. Textures/Spritesheets contains correctly named slices of each original sheet. Full effect frames remain available in the bank as an alternative to split layers.

Expected official-validator warning: the approved 320/640 canvases and certain sheets are non-power-of-two. They are intentionally preserved, with mipmaps disabled and uncompressed sprites; no resizing is required.

Unreal Engine integration guide

OPEN THE DEMO

Open Maps/L_GoblinRaiderIsometricOverview and enter Play. Keys 1-5 select Idle, Walk, Attack, Hurt and Death. The eight numpad directions select the matching facing. The default showcase plays one of each action with the extra 1500 ms corpse inspection hold. Native production Death remains 900 ms.

ADD THE MONSTER

Enable Paper2D. Drag Blueprints/BP_GoblinRaiderIsometric into a level. PlayState(State, Facing) accepts state indices 0-4 and direction indices 0-7 in this order: N, NE, E, SE, S, SW, W, NW. AutoShowcase and DemoControls default false on the reusable Blueprint. ReturnToIdle controls Attack/Hurt recovery; Death stays on its corpse. UpdateAction takes seconds and samples the registered clock without double playback.

VARIABLE TIMING AND CUT TRAIL

Idle 1190 ms and Walk 1100 ms loop. Attack 560 ms, Hurt 400 ms and Death 900 ms play once. Flipbooks store exact millisecond frame runs at 1000 frames/second; this preserves variable pose timing. Cut Back/Front banks synchronize their visible keys to 290-410 ms of Attack, peak 310 ms. The initial/final blank intervals are registration keys, not new artwork. South has no rear effect. Full cut drawings are an alternative; never overlay all three banks.

REGISTRATION

128 production pixels per metre (1.28 pixels per Unreal centimetre), actor scale 1. Image centers align original 256, 320 and 640 canvases. These are image registrations, not anatomical ground pivots. Configure gameplay collisions separately. No body mirroring, alpha trimming, repainting or resizing is applied.

MODIFY AND MIGRATE

Migrate the Blueprint with dependencies through the Content Browser. Inspect each direction in Maps/L_Source_N and the other seven source maps. These useful galleries include all 40 body and 24 alternative effect banks, the original 64 sheet layouts and their actual dependencies. Documentation/L_GoblinRaiderIsometricGuide is the native quick-start map. README.txt and ENGINE-PLAYBACK.json are accessible in the corresponding folder on disk. No Python or C++ authoring tools are required by the product.

SCOPE

One monster in eight directions, not eight monsters or the Pack 02 side-scroller. 312 body frames, 32 main effect frames and 64 optional visibility-layer frames. 64 sheets arrange the same poses. No complete enemy AI, movement/navigation, collision, damage or audio system. NE/SW Death blade tips preserve accepted source truncation. Attack recovery reuses its starting pose.

FLAT 2D DEMO COLORS

The overview DemoMode disables cinematic tone mapping and color grading while Play is active and restores the project override defaults when Play ends. This preserves the approved unlit sprite palette. The reusable monster Blueprint does not change the host renderer. When migrating to another project, configure the destination camera/post-processing for the desired flat 2D appearance; cinematic grading can alter displayed colors. Production PNGs and material colors remain unchanged.
